// how-to

Как правильно зарабатывать на американском YouTube

01 // Подготовка канала

  1. Американский аккаунт Google (регистрация через VPN США).
  2. Название канала на английском, без русских символов.
  3. Настройка AdSense с данными получателя платежей.
  4. Требования монетизации: 1000 подписчиков + 4000 часов просмотра.

02 // Что снимать

  1. Бери нишу из блока выше — они обновляются автоматически.
  2. Сценарий на английском (можно через ChatGPT/Claude).
  3. Озвучка: свой английский или AI-голос (ElevenLabs).
  4. Первые 15 секунд — самые важные, цепляй сразу.

03 // Как снимать

  1. Вертикаль или горизонталь — под формат ниши.
  2. Монтаж: CapCut / DaVinci Resolve (бесплатно).
  3. Субтитры на английском обязательно — это +40% досмотров.
  4. Постинг: 3–5 роликов в неделю, стабильность решает.

04 // Монетизация

  1. AdSense — основной доход США ($5–15 CPM).
  2. Аффилейтки: Amazon, ClickBank, партнёрки в описании.
  3. Перевод прибыли в крипту/карты — обсуди налоги заранее.
  4. Реинвестируй часть дохода в трейдинг (раздел ниже).

Pocket Option

// бинарные опционы

Платформа для торговли опционами с короткими сделками от 1 минуты.

  • Демо-счёт для отработки стратегии без риска.
  • Торгуй только трендом, не лови развороты вслепую.
  • Управление риском: не более 2–5% депозита на сделку.
  • Веди журнал сделок и анализируй ошибки.
